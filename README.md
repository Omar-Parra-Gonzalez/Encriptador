Challenge Alura Latam / Oracle

Este proyecto fue desarrollado como parte de un desafío propuesto por Alura con el objetivo de aplicar los conocimientos adquiridos durante los módulos de formación.

La aplicación fue construida utilizando tecnologías web fundamentales para fortalecer habilidades en desarrollo frontend y lógica de programación.

Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript

Objetivo del proyecto:
Desarrollar una solución funcional e interactiva que permita poner en práctica conceptos como:
- Estructura semántica con HTML
- Estilización y diseño responsive con CSS
- Manipulación del DOM
- Lógica de programación con JavaScript

## 📂 Estructura del proyecto
```bash
├── index.html
├── style.css
├── script.js
└── assets/
```

## ⚙️ Cómo ejecutar el proyecto
1. Clona este repositorio:
```bash
git clone https://github.com/tu-usuario/tu-repositorio.git
```

2. Ingresa a la carpeta del proyecto:
```bash
cd tu-repositorio
```

3. Abre el archivo `index.html` en tu navegador.
